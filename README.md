\# Visual Portfolio System



A programmatic portfolio generator that builds a structured visual CV and project showcase using Python and PIL.



\---



\## Overview



This project is not a static portfolio.



It is a \*\*portfolio generation system\*\* that compiles structured project data into a printable visual CV (PDF format).



It combines:



\* Software projects

\* System design thinking

\* Visual layout automation

\* Structured career presentation



\---



\## Features



\* A4 print-ready portfolio generation

\* Automated layout engine (PIL / Python Imaging Library)

\* Structured project definitions

\* Modular project system

\* Multi-language support (ES / EN planned)

\* Export to PDF

\## Core Concept



Each project is defined as structured data:



\* Name

\* Description

\* Technical focus

\* Functional breakdown

\* Target users



This data is rendered into a consistent visual layout system.



\---



\## Projects Included



\### ERP Commerce System



Full-stack ERP system with inventory, billing, and admin dashboard.



\### Food Calculator



Nutrition tracking and macronutrient calculation system.



\### Dososupli



Supplement tracking and dosage planning system.



\### LinguaLux



Structured language learning application.

High-precision interval training timer for athletic performance.
