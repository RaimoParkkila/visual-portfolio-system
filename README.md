# Visual Portfolio System

Un sistema programático de portafolio que genera y presenta un CV visual estructurado.

---

## Descripción general

Este repositorio contiene un sistema de generación de portafolio que compila proyectos de software en un CV visual estructurado.

La presentación final se entrega como un **documento PDF**, que contiene todas las descripciones y presentaciones de los proyectos.

---

## Proyectos

Todos los proyectos se presentan dentro del PDF del portafolio:

- ERP Commerce System
- Food Calculator
- Dososupli
- LinguaLux
- Chronometer

---

## Salida

El resultado principal de este sistema es:

📄 **Raimo_Portfolio_ES.pdf**

Este archivo contiene la presentación visual completa de todos los proyectos.

---

## Propósito

El objetivo de este portafolio es presentar proyectos de software de forma clara, estructurada y visual para uso profesional y de reclutamiento.

Enfoques principales:
- Desarrollo full-stack
- Aplicaciones móviles
- Diseño de sistemas
- Herramientas de software orientadas al rendimiento
